# Task 6: Nonprofit launch kit (the ALS Association deadline is 3 November 2026)

**Branch:** `agent/nonprofit`  ·  **Your area:** `docs/` (new files) and `site/src/pages/` content only if you add a
page (no design changes)
Read `docs/agent-tasks/RULES.md` and `docs/NONPROFIT_PLAN.md` first.

## Why
AGENCY needs money, partners and real users to exist beyond a hackathon. The ALS Association's Assistive Technology
Grants letter of intent is due **3 November 2026, 1 pm ET** (up to $400,000 over 2 years). Check the current RFA online
and correct any detail that's changed.

## Build (all as clear, ready-to-edit Markdown in `docs/launch/`)
1. **ALS Association LOI draft** that follows the RFA's exact structure and page limits: aims, significance,
   approach, team, distribution plan (free and open), IP control (flag what the team must settle), budget outline.
   Use only true facts from the repo (read the code and docs to describe what exists today and what's simulated).
   Mark every place a human must confirm or fill in with `[[TEAM: ...]]`.
2. **Grant pipeline**: a table of 10+ real, currently open or recurring funders for assistive tech and ALS (with
   links, amounts, deadlines, fit, and eligibility for a student-led project or a fiscally sponsored one). Verify
   each online; mark anything you couldn't verify.
3. **Outreach kit**: emails to ALS clinic speech-language pathologists, the ALS Network's equipment loan program,
   California's Ability Tools, and open-source AAC projects; a one-page PDF-ready summary; a 60-second video script;
   an honest FAQ for families ("is it safe?", "what does it cost?", "what happens to my data?").
4. **Pilot study plan** an IRB would take seriously: research questions, outcome measures used in AAC research
   (cite sources), consent for people who can't speak or write (eye-gaze consent procedures, witnesses, LARs),
   data handling, risks, stopping rules. For UCSC's IRB (check its current process).
5. **Licence decision memo**: options for the code licence given the AGPL RealEye dependency and the nonprofit's
   goals, with a recommendation. Don't add a LICENSE file yourself; the team decides.
6. **Privacy policy and terms of use** drafts that match exactly what the code does (read it), including the AI relay.

## Done means
Every document drafted, sourced (links), honest about what's real today, with `[[TEAM: ...]]` markers for decisions,
and a summary of the most urgent next actions with dates.
